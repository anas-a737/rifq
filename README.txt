رِفْق | RIFQ — نسخة أولية قابلة للتجربة

الملفات:
- index.html: التطبيق.
- manifest.webmanifest: إعدادات التثبيت كتطبيق.
- sw.js: التخزين المؤقت للعمل دون اتصال بعد أول زيارة.

التجربة:
1. افتح index.html لمعاينة الواجهة.
2. لتثبيت التطبيق والعمل دون اتصال، ارفع الملفات إلى استضافة HTTPS (مثل GitHub Pages أو Cloudflare Pages).
3. افتح الرابط عبر Chrome على Android ثم اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق».

التحكم الصوتي:
- زر «تحدث مع رفيق» يستخدم SpeechRecognition عند دعم المتصفح؛ قد يتطلب الإنترنت وإذن الميكروفون.
- «اقرأ مهامي» يستخدم SpeechSynthesis إن كان مدعوماً.
- لا يوجد استماع دائم لعبارة التنشيط «يا رفق»؛ هذا يتطلب تكاملاً خاصاً مع Android أو خدمة خلفية، ولا ينبغي تشغيل الميكروفون باستمرار.

حدود النسخة:
- البيانات محلية على الجهاز الحالي، مع تصدير/استيراد نسخة احتياطية.
- لا توجد مزامنة سحابية بعد.
- مواقيت الصلاة والتنبيهات التلقائية والمساعد الذكي المتصل غير مفعّلة بعد.
- الحديث اليومي مجموعة تجريبية قصيرة من الصحيحين؛ راجع المصدر والنص عند التوسع.
